# Purple Aurora

A private, mobile-first cinematic letter for Yazhini Sri, created by Jaya Surya. It is a single Next.js App Router experience built around atmosphere, restrained motion, optional sound, and an explicit no-pressure message.

## Run locally

```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Personalization

All personal copy and visual options live in `src/config/site.ts`. Update that one file to revise names, story chapters, the letter, wishes, or feature flags. No private data collection, tracking, photo gallery, or response UI is included.

## Deployment

Import the repository in Vercel, use the default Next.js framework preset, and deploy. No environment variables are required.
